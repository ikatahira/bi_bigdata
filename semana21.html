Zona 1 · Eufótica (0 – 200 m)

O que é, de fato, Big Data?

Antes de qualquer coisa: Big Data não é sinônimo de "muitos dados". Um banco de dados de 500 GB não é Big Data só por ser grande — o termo descreve conjuntos de dados tão volumosos, rápidos ou variados que as ferramentas tradicionais (planilhas, bancos relacionais comuns) deixam de conseguir processá-los com eficiência.

Clique nos cards abaixo para comparar os dois mundos.

🗄️

Dado Tradicional

toque para virar
Estruturado, cabe em tabelas, medido em MB/GB, processado em lote (batch), analisado depois que o evento já aconteceu.
🌐

Big Data

toque para virar
Múltiplas fontes e formatos, medido em TB/PB/EB, muitas vezes processado em tempo real, usado para decisões enquanto o evento ainda acontece.
⚠️

O mito comum

toque para virar
"Muitos dados" ≠ Big Data. O que importa é a incapacidade das ferramentas tradicionais lidarem com o volume, a velocidade e a variedade — assunto da próxima semana!

Zona 2 · Disfótica (Crepuscular) (200 – 1.000 m)

Por que Big Data virou assunto agora?

O conceito não é novo, mas só se tornou viável na prática por causa de três movimentos que aconteceram quase ao mesmo tempo:

📱

Explosão de geração

toque para virar
Smartphones, redes sociais, sensores e IoT fazem o mundo gerar, hoje, um volume de dados por dia que superaria décadas de dados até os anos 2000.
💾

Armazenamento barato

toque para virar
Nos anos 80, 1 GB custava milhares de dólares. Hoje custa centavos. Guardar deixou de ser o gargalo.
⚡

Nuvem + processamento distribuído

toque para virar
Ferramentas como Hadoop e Spark, rodando em clusters na nuvem, tornaram possível analisar volumes que antes exigiriam um supercomputador próprio.

Zona 3 · Afótica (Meia-noite) (1.000 – 4.000 m)

Nem todo dado nasce igual

Um dos motivos do Big Data exigir novas ferramentas é a variedade de formatos. Classificamos os dados em três grandes famílias:

📊

Estruturado

toque para virar
Segue um schema fixo, organizado em linhas e colunas. Ex.: tabelas de banco relacional, planilhas.
🧩

Semi-estruturado

toque para virar
Tem alguma organização, mas não é tabular rígido. Ex.: JSON, XML, arquivos de log.
🎞️

Não-estruturado

toque para virar
Sem estrutura predefinida — cerca de 80% de todo o Big Data gerado. Ex.: vídeo, imagem, áudio, texto livre.
