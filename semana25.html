Como processar o passado e o presente ao mesmo tempo

Até aqui, tratamos o processamento em blocos (batch). Mas e quando é preciso reagir a um pedido assim que ele acontece, sem perder a precisão de reprocessar todo o histórico? Duas arquiteturas respondem a essa pergunta.

🌀

Batch Layer

toque para virar
Reprocessa periodicamente todo o histórico de dados. Visão completa e precisa, mas com atraso (ex.: rodar toda madrugada).
⚡

Speed Layer

toque para virar
Processa os dados novos assim que chegam. Visão aproximada, mas quase em tempo real — ideal para alertas imediatos.
🔱

Lambda Architecture

toque para virar
Combina Batch Layer + Speed Layer numa Serving Layer única, que responde consultas usando o melhor das duas visões.
🌊

Kappa Architecture

toque para virar
Simplifica a Lambda: tudo passa por um único pipeline de streaming, sem manter duas arquiteturas separadas — menos complexidade operacional.
